# fetchwasm

Fetch URLs and wasm query parts with stable normalization.

**Site:** https://theworker02.github.io/fetchwasm/

## Install / run

```bash
git clone https://github.com/theworker02/fetchwasm.git
cd fetchwasm
node src/cli.js
node --test
```
